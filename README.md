# Hi, I'm Dane 👋

I build **[Mokxi](https://mokxi.com)**. It's an electronics workbench that runs in your browser. Drop a board and some parts next to the code editor and hit Run. The circuit and the code run together in real time. Nothing to install.

I'm building it solo. My other projects are on 🐝 **[danedolph.com](https://danedolph.com)**.

## Mokxi at a glance

- 7,300+ makers, students and teachers since September 2026 and paying customers
- 45 simulated boards like Arduino, ESP32, Raspberry Pi and STM32 plus hundreds of parts
- Lessons and a weekly challenge for learners
- Classrooms with auto-graded assignments for teachers
- An EE lab for exam prep
- Works inside ChatGPT and Claude with its own MCP server. There's a VS Code extension and a CLI too.

**[Try it at mokxi.com →](https://mokxi.com)**

## What I built

- **CPU emulators in Rust compiled to WebAssembly.** Real Arduino and ESP32 firmware runs right in the tab.
- **A circuit simulator.** It handles diodes, transistors and op-amps and gets checked against ngspice.
- **A C++ compiler in the browser.** Sketches compile on your own machine. MicroPython and CircuitPython run too.
- **Everything around it.** Accounts, live collab, classrooms, billing and support all on Cloudflare.
